# 588080 V3G 每日规则信号提醒

这是一个独立、无账户信息的 GitHub Actions 项目。每个工作日中国时间
15:40，它会读取 588080 的腾讯证券前复权日线，计算冻结的 V3G 规则，
保存当日报告，并可通过飞书群自定义机器人推送。它不读取
`daily_stock_analysis`，也不会修改其他项目。

## 它会告诉你什么

- 行情是否已更新到当天；
- 15 组参数中有多少组支持持仓；
- 今天是“买入提醒、卖出提醒、继续持有、观望”中的哪一种；
- 用一句简单中文说明下一步；
- 规则是否发生了真正的买卖变化。

### 四种提醒是什么意思

- `🟢 买入提醒`：规则今天首次从观望转为持有；如决定跟随，下一交易日人工确认。
- `🔴 卖出提醒`：规则今天首次从持有转为观望；如决定跟随，下一交易日人工确认。
- `🔵 继续持有`：规则仍保持持有，今天没有新的卖出变化。
- `🟡 观望`：规则没有新的买入变化，不等于今天新发出卖出提醒。

内部计算仍使用 `CASH` 代码表示“规则未持有588080”，但推送消息不再显示该英文术语。

如果行情没有更新到当天，程序只提示等待，不产生规则买卖动作。
腾讯行情暂时不可用时，程序会尝试 Baostock 前复权日线，并与仓库内的
已核对历史快照比较复权口径；两者都不可用时只读取快照并显示“观望”，
不会用过期数据产生新的买入或卖出提醒。

## 它不会做什么

- 不读取证券账户、持仓、成本或资金；
- 不连接券商，不自动下单；
- 不承诺收益，也不把规则信号包装成个性化投资建议。

## 飞书接入（Webhook 不要发到聊天中）

1. 在飞书群中打开“设置 → 群机器人 → 添加机器人 → 自定义机器人”。
2. 建议开启“签名校验”，分别复制 Webhook 和签名密钥。
3. 打开本仓库 `Settings → Secrets and variables → Actions`。
4. 新建仓库 Secret：`FEISHU_WEBHOOK_URL`，值为完整 Webhook。
5. 新建仓库 Secret：`FEISHU_WEBHOOK_SECRET`，值为签名密钥。未开启签名校验时可不建第二项。
6. 打开 `Actions → V3G daily rule signal → Run workflow` 做一次手动测试。

旧名称 `FEISHU_WEBHOOK` / `FEISHU_SECRET` 也继续兼容。没有配置 Webhook 时，
任务仍会成功生成报告，但不会发送消息。

## 冻结规则

- MACD：12、26、9；
- 均线：40、50、60、80、100 日；
- MACD 连续确认：1、2、3 日；
- 共 15 票，空仓时达到 10 票转为持仓，持仓时降到 6 票转为空仓；
- 中间票数保持上一状态；
- 收盘计算，状态切换时只提示下一交易日开盘的规则动作；
- 信号规则指纹：`daf0be01dad72917ecb41fbd94f7d9775570b0bdaa4c4d7ddc5d1dbd38ee9292`。

该指纹只包含信号参数，不包含真实账户资金、持仓、成本或交易费率。

若要修改参数，应创建新规则版本和新指纹，不应覆盖已有版本。
